# LevelUp App

![LevelUp App Screenshot](screenshot.png) 

## Overview

The LevelUp App is designed to enhance productivity and community engagement. With features like groups, events, tasks management, and a shopping cart for merchandise, it provides a comprehensive platform for users to connect and collaborate.

## Features

- **Groups:** Create and join groups to collaborate on projects and share ideas.
- **Feed:** Stay updated with a dynamic feed of posts and activities from your groups.
- **Events:** Organize and participate in events to foster community engagement.
- **Tasks Management:** 
  - **Primary Tasks:** Manage your main tasks with deadlines and priorities.
  - **Secondary Tasks:** Break down primary tasks into smaller, manageable steps.
- **User Authentication:** Secure login and logout functionality with validation.
- **Cart:** Add items to your cart for easy shopping of merchandise.
- **Shopping Merchandise:** Browse and purchase items directly from the app.
- **Notifications:** Receive updates on group activities, events, and task deadlines.

## Requirements

- iOS 14.0 or later
- Xcode 12.0 or later

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/levelup-app.git
   ```
2. Open the project in Xcode:
   ```bash
   open levelup-app.xcodeproj
   ```
3. Build and run the project on a simulator or a physical device.

## Usage

- **Login/Logout:** Access the app securely by logging in or out.
- **Explore Groups:** Create or join groups to connect with others.
- **Check the Feed:** Browse the feed for updates and posts from your groups.
- **Manage Tasks:** Add and organize primary and secondary tasks.
- **View Events:** Discover and participate in upcoming events.
- **Shop Merchandise:** Browse and add items to your cart for purchase.
